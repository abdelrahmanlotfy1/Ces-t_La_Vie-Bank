# 🏦 C'EST LA VIE BANK
### C# Banking Management System

A console-based banking management application developed using C# and Object-Oriented Programming principles.

## 🚀 Features
- Customer registration
- Bank account creation
- Savings and Current accounts
- Deposit and Withdrawal operations
- Money transfers
- Transaction management
- Custom exception handling
- Delegates and Events
- Low-balance notifications
- Transaction logging

## 🛠️ Technologies
- C#
- .NET 8
- Object-Oriented Programming (OOP)
- Delegates and Events
- Exception Handling

## 🏗️ Project Structure
- `Program.cs` – Application entry point
- `Account.cs` – Base account class
- `Savingaccount.cs` – Savings account
- `CurrentAccount.cs` – Current account
- `BankServices.cs` – Banking operations
- `Customer.cs` – Customer model
- `Transaction.cs` – Transaction model
- `Notifications.cs` – Notification handling

## ▶️ How to Run

1. Install .NET 8 SDK.
2. Clone or download this repository.
3. Open the project file in Visual Studio.
4. Build and run the application.
